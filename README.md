# AstroCheck Pro (Streamlit)

Εφαρμογή ελέγχου Astrodienst Data Sheet και δημιουργίας πλήρους εντολής/Word με μόνιμα ενσωματωμένες τις οδηγίες v4 και το πρότυπο ύφους της Έλενας.

## Απαιτήσεις

- Python 3.10+ (ο κώδικας χρησιμοποιεί `list[X]` γενικά τύπους και `X | None` ενώσεις).

## Εκτέλεση

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run app.py
```

Προαιρετικές μεταβλητές περιβάλλοντος (δεν χρειάζονται αλλαγή κώδικα):

```bash
export ASTROCHECK_MODEL=gpt-5.4              # ή gpt-5.6, όποτε επιβεβαιωθεί ότι είναι διαθέσιμο στον λογαριασμό σου
export ASTROCHECK_MAX_OUTPUT_TOKENS=40000    # αύξησέ το αν η παραγωγή διακόπτεται ημιτελής
```

## Ροή

1. Ανέβασμα μόνο του νέου Astrodienst PDF. Οι οδηγίες v4 και το πρότυπο Έλενας φορτώνονται αυτόματα. Δοκιμασμένο σε αρχεία τύπου D2GW και W2GW.
2. Ανάγνωση πλανητών, ακμών, Οίκων, ανάδρομης κίνησης και πίνακα όψεων· αυστηρός έλεγχος ότι βρέθηκαν οι 10 βασικοί πλανήτες, ο Βόρειος Δεσμός, ο Χείρωνας, ακριβώς 12 ακμές, και ότι ο τεχνικά υπολογισμένος Οίκος κάθε σημείου συμφωνεί με αυτόν που αναφέρει το ίδιο το φύλλο δεδομένων.
3. Υποχρεωτική οπτική επιβεβαίωση τετραγώνων/αντιθέσεων.
4. Συμπλήρωση προσωπικού πλαισίου και γλώσσας. Δημιουργία αυτόματα (με OpenAI API key) ή χειροκίνητα (λήψη master prompt, χρήση σε ChatGPT, επικόλληση της απάντησης πίσω στην εφαρμογή).
5. **Αυτόματος έλεγχος πληρότητας** πάνω στο τελικό κείμενο -- πριν το Word γίνει διαθέσιμο για λήψη, επαληθεύεται ότι κάθε υποχρεωτικό τετράγωνο/αντίθεση αναφέρεται με το σωστό orb, ότι υπάρχουν και οι 12 Οίκοι, και ότι υπάρχουν οι τέσσερις τελικές ενότητες. Αν λείπει κάτι, η λήψη παραμένει κλειδωμένη και εμφανίζεται ακριβής λίστα των ελλείψεων.
6. Λήψη Word.

## Σημείωση για τις όψεις Ωροσκόπου/Μεσουρανήματος

Ο πίνακας του Astrodienst εμφανίζει ως σημεία όψεων τον Ωροσκόπο και το Μεσουράνημα, όχι ξεχωριστές γραμμές για τη Δύση και τον Πυθμένα Ουρανού. Η εφαρμογή δεν διπλασιάζει αυτές τις όψεις σε δύο ανεξάρτητες καταχωρήσεις· αντ' αυτού προσθέτει σε κάθε τέτοια όψη μια σύντομη σημείωση ότι ενεργοποιείται ταυτόχρονα και το απέναντι άκρο του άξονα (με τον σωστό, μετασχηματισμένο τύπο όψης -- π.χ. μια σύνοδος με τον Ωροσκόπο ισοδυναμεί με αντίθεση προς τη Δύση).

## Ασφάλεια

Το OpenAI API key που δίνεις στην καρτέλα 4 δεν αποθηκεύεται από την εφαρμογή σε δίσκο ή βάση δεδομένων, αλλά περνά από τον server όπου τρέχει το Streamlit προς το OpenAI. Για καθαρά τοπική χρήση (`streamlit run app.py` στον υπολογιστή σου) αυτό δεν έχει πρακτική σημασία. Αν σκοπεύεις δημόσιο deployment (π.χ. Streamlit Community Cloud) για χρήση από άλλους, έχε υπόψη ότι όποιος διαχειρίζεται τον server έχει τεχνικά πρόσβαση στα κλειδιά που περνούν από εκεί.

## Σημαντικό

Η εφαρμογή δεν αντιμετωπίζει την αστρολογία ως επιστημονική ή ψυχολογική διάγνωση. Η Θεωρία των Μοιρών χρησιμοποιείται μόνο συμπληρωματικά. Η τελική ανάλυση πρέπει να περνά ανθρώπινο μαθηματικό, γλωσσικό και οπτικό έλεγχο -- ο αυτόματος έλεγχος πληρότητας βοηθά, αλλά δεν αντικαθιστά αυτόν τον τελικό έλεγχο.

## Γνωστός περιορισμός

Ο `parser.py` βασίζεται σε συντεταγμένες pixel συγκεκριμένες για τη σημερινή μορφή των Astrodienst PDF (δοκιμασμένος σε τύπους D2GW και W2GW). Μια μελλοντική αλλαγή μορφοποίησης από την Astrodienst μπορεί να τον επηρεάσει· ο αυστηρός έλεγχος στο βήμα 2 θα σταματήσει την εφαρμογή με σαφές μήνυμα αντί να προχωρήσει σιωπηλά με λάθος δεδομένα, αλλά αξίζει επανέλεγχος αν κάποιο PDF μοιάζει διαφορετικό.
